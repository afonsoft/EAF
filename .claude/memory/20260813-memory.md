- Subscription payment lifecycle implementation completed on `devin/1786700000-subscription-payments-lifecycle`.
  - Extended `SubscriptionPayment` with `IsRecurring`, `IsProrationPayment`, `InvoiceNo`, `ExtraProperties`, `GatewaySubscriptionId` and `Products` collection.
  - Added `SubscriptionPaymentProduct` entity and `EditionPaymentType.Downgrade`.

  - Extended `StripePaymentGateway` with recurring checkout, subscription status, cancellation and webhook processing.
  - Added `ISubscriptionPaymentGateway` interface and `SubscriptionRenewalWorker` Hangfire recurring job with fault-tolerant registration.
  - Added `PaymentWebhookController` for anonymous gateway webhooks.

  - `dotnet build Eaf.sln` 0 warnings / 0 errors; `dotnet test` passed except one flaky SQLite cache timing test.

## Decisions

- Kept `PaymentAppService` as a thin wrapper over `PaymentManager` to preserve existing gateway/settings endpoints.
- Avoided `IQueryable.Include` in `PaymentManager` to keep repository substitution testable.
- Webhook endpoint reads raw request body and uses `Stripe-Signature` header by default, falling back to `X-{gateway}-Signature`.
- Template EF Core migration for `SubscriptionPaymentProduct` was not added because `Eaf.ProjectName.*` template projects reference `Eaf.Middleware.Core` via NuGet package 9.4.3 and cannot see the new source entity until a package is published.

## Lessons learned

- Stripe.net 52.1.0: `Invoice.SubscriptionId`/`PaymentIntentId` do not exist; use `invoice.Parent.SubscriptionDetails.SubscriptionId` and `invoice.Payments.Data.FirstOrDefault().Payment.PaymentIntentId`.
- Stripe.net 52.1.0: `Subscription.CurrentPeriodEnd` does not exist; read `subscription.Items.Data.FirstOrDefault().CurrentPeriodEnd`.
- Stripe.net 52.1.0: `EventUtility.ConstructEvent` overload with three string parameters does not exist; use the five-parameter overload.
- `RecurringJob.AddOrUpdate` can throw during `PostInitialize` if Hangfire storage is unreachable in tests; wrap it in try/catch with logging, mirroring existing patterns.
